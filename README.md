# Куратор — посещаемость, расписание и студенты

Веб-приложение для старосты и куратора группы. Telegram-бот необязателен — при токене добавляет уведомления и команды.

## Что умеет

**Главное — опрос перед парой.** За 15 минут (настраивается) студенту приходит опрос: «✅ Буду / ⏰ Опоздаю / ❌ Не смогу» — в Telegram при подключённом боте, иначе в ленте приложения. Кто промолчал до сводки — получает «не ответил» (= пропуск). При «Не смогу» спрашивается, уважительная ли причина, и принимается текст или фото справки. Через 10 минут после начала пары старосте приходит сводка: кто на паре, кто опаздывает, кто не придёт, кто молчит, и предупреждения о прогулах.

| | |
|---|---|
| 📊 **Живая сводка** | На главной — кольцевая диаграмма по текущей паре, обновляется сама |
| 🔑 **Код на доску** | Защита от «сказал буду, а сам не пришёл»: 4 цифры на 3–20 минут, отметиться можно только своим аккаунтом |
| 📅 **Журнал** | Календарь месяца с отметками → таблица «студенты × пары», правка в одно касание, справки студентов |
| ⚠️ **Прогулы** | Порог пропусков по предмету за семестр, кто «на грани», уведомления старосте |
| 📒 **Успеваемость** | Загрузка ведомости «Сведения успеваемости … за месяц» из Excel: оценки по дисциплинам, пропущенные часы, примечания. Каждый студент видит свои оценки, средний балл, место в группе и динамику по месяцам (/grades). Староста и куратор — средний балл, качество знаний, % успеваемости, долги; правка оценок; выгрузка ведомости в том же виде; пропуски часов из журнала |
| 🗓 **Расписание** | Отдельный вид для нечётной и чётной недели (текущая отмечена), кнопка «Разделить» делает раздельное расписание, даты семестра, каникулы/сессии/практика, разовые пары, заметки для студентов, **импорт из Excel бесплатно** (/import) |
| 📥 **Excel для деканата** | Сводка с процентами + цветной журнал за любой период |
| 📈 **Статистика** | Средняя посещаемость, динамика, по предметам, по студентам. Студент видит свою |
| 📢 **Объявления** | С заголовком и закреплением, приходят всем в личку |
| 📚 **База знаний** | Методички и конспекты по предметам: загрузка и скачивание прямо в приложении |
| 👥 **Роли и права** | **Староста** и **зам. старосты** — все права. **Куратор** — по умолчанию журнал, статистика, отчёты, объявления, ведомость, данные студентов (ФИО, № студенческого, контакты, дата рождения, родители) и удаление лишних студентов (фильтр «Нет в ведомости», массовое удаление, объединение дублей). **Студент** — опросы и свои пропуски. Куратору и любому студенту права выдаются по отдельности (10 переключателей). Куратор вступает по отдельной ссылке из «Пригласить». Статус «отчислен» |
| 🗒 **Итоги недели** | По воскресеньям старосте — средняя посещаемость и кто больше всех пропускал |

Дизайн: адаптируется под светлую/тёмную тему Telegram, плавные анимации (появление карточек, скользящая навигация, шторки со свайпом, анимированные диаграммы, конфетти, когда все на паре).

Команды бота (при подключённом `BOT_TOKEN`): `/today`, `/tomorrow`, `/week` (с переключением недель), `/here 1234`, `/stats`, `/grades`, `/remind on|off`, `/invite`, `/announce текст`, `/export [дней]`, `/import`, `/help`.

> При обновлении со старой версии база `data/kurator.db` обновится автоматически — данные сохранятся.

## Запуск

1. Скопируйте `.env.example` в `.env` и впишите `WEBAPP_URL` — публичный **HTTPS**-адрес приложения:
   - для теста: установите [ngrok](https://ngrok.com), запустите `ngrok http 8080`, скопируйте адрес `https://….ngrok-free.app`;
   - для постоянной работы: VPS с доменом и nginx/Caddy (прокси на порт 8080), либо хостинг типа Railway/Render/Amvera.

   `BOT_TOKEN` можно оставить пустым — всё, кроме уведомлений и команд в Telegram, работает без него.
2. Запустите:
   - **Windows:** дважды кликните `run.bat` (нужен Python 3.11+ с python.org).
   - **Linux/macOS:**
     ```bash
     python3 -m venv .venv && . .venv/bin/activate
     pip install -r requirements.txt
     python bot/main.py
     ```
   - **Docker:** `docker build -t kurator . && docker run -d --env-file .env -v $(pwd)/data:/app/data -p 8080:8080 kurator`
3. Создайте первую группу и её владельца:
   ```bash
   python bot/setup_admin.py "ИВТ-21" ivanov 'S3cret-Pass'
   ```
   Владелец заходит на сайт → «Войти по паролю» → добавляет студентов и раздаёт им коды первого входа (студенты тоже заходят без Telegram).

> Без Telegram события приходят в ленту приложения (Android — пушами); браузер без открытой вкладки уведомления не получает.

### Подключение Telegram (необязательно)

В [@BotFather](https://t.me/BotFather): `/newbot` → токен → впишите в `BOT_TOKEN` в `.env` и перезапустите. Бот сам выставит кнопку «Открыть» (меню) и список команд, студенты смогут входить по `/start` и получать опросы, напоминания и объявления личными сообщениями.

> Если `WEBAPP_URL` не задан — бот работает только командами, без приложения.

## Установка на свой сервер (VDS, Linux)

Домен не нужен: бот сам возьмёт адрес вида `1.2.3.4.sslip.io` по IP сервера и получит для него HTTPS-сертификат.

**Самый простой способ — с Windows:**
1. Закройте окно `run.bat` (сервер на компьютере должен быть остановлен).
2. Дважды кликните `deploy\upload.bat`, введите IP сервера, пользователя (обычно `root`) и пароль.
3. Через 2–3 минуты сервер работает. Тот же `upload.bat` потом используйте для обновлений — база и настройки сохранятся.
4. На чистой установке создайте первую группу: `sudo -u kurator bash -c 'cd /opt/kurator && .venv/bin/python bot/setup_admin.py "Группа" логин пароль'`

**Вручную:** загрузите папку проекта на сервер (WinSCP / scp) и выполните в ней `sudo bash deploy/install.sh` (или `sudo bash deploy/install.sh bot.mysite.ru` для своего домена).

Что делает установщик: Python-окружение в `/opt/kurator`, сервис `kurator` (автозапуск и перезапуск при сбое), HTTPS через Caddy (или через nginx, если он уже стоит), открывает порты 80/443, переносит базу с компьютера и каждую ночь делает резервную копию — при заданном `BOT_TOKEN` и `CURATOR_IDS` она приходит главному куратору в Telegram, иначе просто лежит в папке `backups/`.

| | |
|---|---|
| Логи | `journalctl -u kurator -f` |
| Перезапуск | `systemctl restart kurator` |
| Настройки | `/opt/kurator/.env` |
| Копия базы вручную | `sudo -u kurator bash /opt/kurator/deploy/backup.sh` |

## Приложение для Android

Папка `android/` — отдельное приложение (иконка на телефоне, вход по логину/паролю или через подтверждение в Telegram, тот же аккаунт и данные).
Собирается прямо на сервере: `sudo bash /opt/kurator/android/build_apk.sh` (или ответ `y` в `deploy\upload.bat`),
после чего ссылка на установку показывается в приложении (а при подключённом боте — командой **/app**). Подробности — `android/README.md`.
Тот же вход работает и в обычном браузере на компьютере: просто откройте адрес сервера.

## Как пользоваться

1. Староста: группа создана через `setup_admin.py` (или «Создать группу» в приложении) → вкладка «Студенты» → «+ Добавить» (вставьте список ФИО, по одному в строке).
2. «Расписание» → «+ Добавить пару». В «Ещё» укажите начало семестра — заработают чётные/нечётные недели.
3. «Студенты» → «Пригласить» → отправьте ссылку в чат группы. Студенты переходят, жмут на свою фамилию.
4. На паре: «Сегодня» → нажать на пару → отметить или открыть самоотметку по коду.
5. «Статистика» → «Отчёт в Excel».

## Устройство

```
bot/
  main.py      запуск: веб-сервер + планировщик (+ бот, если задан BOT_TOKEN)
  handlers.py  команды чат-бота
  api.py       HTTP API приложения (вход по Telegram initData или по паролю)
  db.py        SQLite — файл data/kurator.db, ничего ставить не нужно
  logic.py     даты, чётность недель, статистика
  excel.py     отчёт .xlsx
  polls.py     опрос перед парой и сводка старосте
  tasks.py     планировщик (опросы, сводки, итоги недели)
  perms.py     роли и права доступа (+ вход в приложение по токену: api.py, таблицы app_logins/app_sessions)
  names.py     сопоставление ФИО без учёта регистра («антонюк алексей» = «АНТОНЮК А.С.»)
  grades.py    ведомость успеваемости: разбор Excel, показатели, выгрузка
  state.py     состояния диалогов (ожидание файла, причины)
webapp/        Mini App: index.html, app.css, app.js (ядро), views.js (экраны) — без сборки
```

Резервная копия = скопировать файл `data/kurator.db`.
