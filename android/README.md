# Приложение «Куратор +» для Android

Лёгкая оболочка над веб-приложением бота: журнал, оценки, расписание, опросы — всё то же, что в Mini App,
но отдельной иконкой на телефоне и без Telegram на экране. Данные приходят с вашего сервера, поэтому
после обновления бота приложение переустанавливать не нужно.

**Вход** — кнопкой «Войти через Telegram»: бот присылает «Вход в приложение?», вы нажимаете «Да, это я».
Аккаунт тот же, что в боте: группа, роль, права и оценки сохраняются. Выйти на всех телефонах — `/logout_all` в боте.

## Как получить APK

**Проще всего — собрать на сервере** (там, где работает бот):

```bash
sudo bash /opt/kurator/android/build_apk.sh
```

или в `deploy\upload.bat` ответить `y` на вопрос «Собрать приложение для Android?».
Первый раз скрипт поставит Java 17 и Android SDK (~600 МБ) и соберёт приложение за 5–10 минут.
Готовый файл раздаётся по адресу `https://<ваш адрес>/app.apk`; ссылку показывает команда **/app** в боте
и пункт «Ещё → Приложение для Android» в Mini App.

**Или в Android Studio:** откройте папку `android`, впишите `serverUrl=` в `gradle.properties`,
Build → Generate Signed App Bundle / APK → APK.

## Установка на телефон
Откройте ссылку `…/app.apk` на телефоне → «Скачать» → откройте файл. Android попросит разрешить
установку из браузера/Telegram — разрешите. При обновлении просто установите новый APK поверх.

## Что внутри
- `app/src/main/java/ru/kurator/app/MainActivity.java` — WebView, вход, кнопка «Назад», ссылки в Telegram, выбор файлов
- `app/src/main/assets/offline.html` — экран «Нет связи»
- `app/src/main/res` — иконка (шапочка выпускника), заставка, светлая и тёмная тема
- `build_apk.sh` — сборка и подпись на сервере (ключ хранится в `/opt/kurator/android-keystore`, копия — в `backups`;
  **не удаляйте его**, иначе новую версию нельзя будет поставить поверх старой)

Требования: Android 8.0 и новее.
